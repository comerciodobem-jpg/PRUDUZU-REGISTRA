# Óris 360 — Base de Conhecimento do Projeto

Este repositório passa a funcionar também como base estruturada de conhecimento para agentes de IA e desenvolvedores.

## Projeto documentado

### Produzir Registra

Aplicativo operacional do módulo de Produção do Óris 360. O objetivo é registrar a produção real com o mínimo de burocracia, preservar a identificação de quem produziu, proteger a confiabilidade do estoque e transformar os registros em rastreabilidade e indicadores úteis.
